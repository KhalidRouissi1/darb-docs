## Extension requirements

Use Node.js 20.19+ and npm. For the documentation site, use Node.js 22.23.4 or newer; Node.js 24 LTS is a suitable shared environment.

## Build the extension

In your terminal:

```sh
git clone https://github.com/KhalidRouissi1/darb-youtube.git
cd darb-youtube
npm ci
npm run build
```

In your Chromium browser's extension manager, enable Developer mode and choose **Load unpacked**. Select `.output/chrome-mv3` inside the repository. That directory is generated build output, not a folder users of the npm companion need to download.

After a rebuild, reload the extension and refresh already-open video pages. Firefox development builds can be loaded temporarily through `about:debugging`; permanent installs require a Mozilla-signed package.

## Run extension checks

```sh
npm run typecheck
npm test
npm run build:firefox
```

If you change the companion, run `npm run test:mcp-package` as well. Follow the repository's architecture guide before changing progress, storage, permissions or tab ownership.

## Work on the documentation

The site lives in its own [documentation repository](https://github.com/KhalidRouissi1/darb-docs):

```sh
git clone https://github.com/KhalidRouissi1/darb-docs.git
cd darb-docs
npm ci
npm run verify
```

Run the site's local development server:

```sh
npm run dev
```

Open the local URL printed in the terminal. To test the production search index,
run `npm run build`, then `npm run preview`. Portless can wrap the server in
environments that use named HTTPS development URLs.

Public deployment and GitHub/npm publication are separate maintainer actions.
