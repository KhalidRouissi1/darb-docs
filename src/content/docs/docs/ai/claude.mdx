## Check registration

In your terminal, use:

```sh
claude mcp list
```

Look for `darb-live` or `darb-snapshot`, depending on your mode. In a fresh Claude Code session, inspect `/mcp` and ask the test question. Approve any client tool-access prompts you understand.

If a Darb action is proposed, review it in Darb → Assistant. A client tool permission does not replace Darb's separate approval for playback or saving a playlist.
