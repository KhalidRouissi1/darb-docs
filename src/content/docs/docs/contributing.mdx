## Useful contributions

Help with reproducible playback bugs, accessibility, installation guides, design, translations or focused feature proposals. For larger changes, open an issue describing the problem before implementing a new system.

Read the repository's [contribution guide](https://github.com/KhalidRouissi1/darb-youtube/blob/main/CONTRIBUTING.md), [code of conduct](https://github.com/KhalidRouissi1/darb-youtube/blob/main/CODE_OF_CONDUCT.md) and [issues](https://github.com/KhalidRouissi1/darb-youtube/issues).

## Improve these docs

Use **Edit this page** on a guide in the [documentation repository](https://github.com/KhalidRouissi1/darb-docs). Content lives in `src/content/docs/`. Tutorials are listed in `src/data/tutorials.ts`; add the recording's video ID, actual duration and chapters when it is ready.

Keep steps aligned with a real released version. Test every command you change and exclude connection files, credentials, private courses and personal screenshots.

## Report a bug

Include browser/OS versions, extension version, reproducible steps, expected behavior and safe error details. For MCP, include the companion version and whether you use live mode or a snapshot.

## Build and review

[Build locally](/docs/development/) and run the checks for the area you changed. Explain the user-visible result and how a reviewer can verify it. Contributions use the project's MIT license.
