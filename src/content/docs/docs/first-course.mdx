You need Darb installed and a recorded YouTube video with a known duration.

<Tutorial id="first-course" />

## Create a course

1. Open the video itself, rather than YouTube's homepage or search results.
2. Click the Darb extension icon.
3. Confirm the displayed title matches the video you're watching.
4. Choose a **Study per day** duration, or enter a custom number of minutes.
5. Create the course using the popup's primary action.

A homepage with many video cards is a place to select a playlist. It is not itself a single video course.

## Start a session

Start the course's next session. Darb opens or reuses the video's learning tab and tracks playback there. At the session boundary, it pauses and offers the next step.

If you already watched part of the video, select the session you want to study. Continue from the active session rather than assuming that earlier unfinished sessions must come first.

## Leave and return

Play for a moment, leave the course, then open Darb and continue it. Your saved checkpoint should bring you back near where you stopped.

**Success check:** the right title is shown, the intended session starts, and progress survives closing and reopening the popup.
