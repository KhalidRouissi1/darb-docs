## Choose your distribution

Darb is available on the Chrome Web Store. Use the store installation for automatic browser updates.

| Distribution | Where to get it |
| --- | --- |
| Chrome, Brave and Edge | [Chrome Web Store](https://chromewebstore.google.com/detail/darb/abfplmdaigobogelhdalmbcmlhdocloj) |
| Firefox | [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/darb/) |
| Unpacked Chromium extension | [GitHub Releases](https://github.com/KhalidRouissi1/darb-youtube/releases/latest) |
| MCP companion | [npm package](https://www.npmjs.com/package/@khalidrouissi/darb-mcp) |

These are separate distributions. A companion update does not update your browser extension. The store listing's **Details** section shows the published version; your browser's extension manager shows your installed version.

## Source and store versions

The public extension source targets **0.5.9**, including the workspace, playlists, timestamped notes, optional assistant access and experimental HackerTube support. A source commit does not mean the same version is already available in a store.

Check the [extension changelog](https://github.com/KhalidRouissi1/darb-youtube/blob/main/CHANGELOG.md) against your installed version. If the store has not received a feature you need, follow the [development build guide](/docs/development/).

The MCP companion has its own version. Check npm before following version-specific setup instructions; changes marked unreleased in the changelog are not necessarily published.

## Update carefully

Use the same browser profile and extension entry to retain local course data. Store installations receive signed store updates. Unpacked builds require a manual download, replacement and reload; follow the [local update instructions](/docs/install/#update-a-local-installation).

## Follow changes

Use [GitHub releases](https://github.com/KhalidRouissi1/darb-youtube/releases) for published downloads and version notes. Report a regression with the exact browser extension and companion versions; they may differ.
