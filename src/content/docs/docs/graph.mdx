## What a connection means

The graph shows relationships you saved: courses prepared in playlists, linked notes, shared tags, related-material links and optional folders. It does not infer what you understand or grade your knowledge.

## Find a useful view

1. Open Graph from the dashboard.
2. Select a node to inspect its material.
3. Choose **Focus** for nearby connections or **Whole workspace** for an overview.
4. Filter node types, zoom, pan or drag nodes to arrange the view.

Use **Reset layout** to start the arrangement again. Positions are saved locally.

## Keyboard and large libraries

Open nodes with Enter or Space, or use the connection list. The graph limits drawn nodes and edges for responsiveness and shows a notice when a large view is truncated. Use filters or Focus to narrow it down.
