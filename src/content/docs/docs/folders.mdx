---
title: "Folders and tags"
description: "Organize learning material with folders, nested folders and topic tags."
---

## Create a folder

In Library, choose **New folder**. Set a parent if the folder belongs inside another folder. New material begins in Inbox until you move it.

## Move an item

Open the item's inspector and choose its folder. For several items, select their checkboxes, choose a folder under **Move to…**, then press **Move**. Look for the destination confirmation.

Dragging an item onto a folder is an alternative. Use the folder menu to rename, move, reorder or delete a folder.

## Add topics with tags

Edit an item's tags in the inspector. Use a few topics that help you find it later, such as `python` or `beginner`. Bulk tag replacement replaces the selected items' tags; review the selection first.

## Delete a folder

Deleting a folder moves its contents to Inbox. It does not delete courses, notes or playlists, and it does not reset course progress.

Folders, tags and graph layout are not included in current MCP sharing.
